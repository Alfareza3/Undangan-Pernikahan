# 💒 Wedding Invitation Website Template

Template website undangan pernikahan elegan yang dibuat dengan **HTML**, **CSS**, dan **Bootstrap 5**.  
Dirancang untuk menampilkan informasi pernikahan secara modern, estetis, dan responsif.

---

## ✨ Fitur Utama

- 🎉 Hero section pembuka dengan kutipan islami (bisa diganti)
- 📆 Informasi lengkap acara (tanggal, waktu, lokasi)
- 📸 Carousel galeri foto prewedding
- 🎶 Background music otomatis (dengan audio player)
- 🗺️ Google Maps lokasi acara (embed)
- 📝 Kutipan cinta dengan gaya elegan
- 🌗 Tema gelap yang lembut dan modern
- 📱 Desain responsif (mobile-friendly)
- 💫 Animasi scroll dengan AOS

---

## 🧰 Teknologi yang Digunakan

- HTML5 & CSS3
- [Bootstrap 5](https://getbootstrap.com/)
- [Google Fonts - Sacramento](https://fonts.google.com/specimen/Sacramento)
- [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)

---

## 🚀 Cara Pakai

1. Download atau clone repository ini.
2. Ganti:
   - Nama pasangan
   - Informasi tanggal & lokasi
   - Foto-foto (di carousel)
   - Musik (opsional)
3. Upload ke hosting seperti:
   - GitHub Pages
   - Netlify
   - Vercel
